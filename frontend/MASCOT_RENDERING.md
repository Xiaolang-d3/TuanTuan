# 登录页吉祥物渲染记录

## 现象与排查

登录页吉祥物右侧出现横向条纹或拉扯。桌面浏览器对照中，启用 WebGL 动画时能够复现，切换到减少动态效果、使用静态图片时未见条纹；临时关闭 WebGL2 mipmap 后，该测试环境中的条纹消失。

素材的全透明区域含有非零 RGB 数据，但这不代表静态图片中这些像素可见。纹理过滤和透明度处理与问题相关，具体浏览器、GPU 或合成机制尚未确定，不能把透明像素 RGB 残留断定为唯一根因。

## 当前处理

`src/components/mascotRenderer.ts` 使用线性纹理过滤，不生成 mipmap；上传纹理前通过 2D 画布清理全透明像素。用户反馈修改后异常消失，但仅凭这一结果不能判定哪一处修改在其设备上起了决定性作用。

## 避免回归

- 更换素材、纹理过滤方式或透明度配置时，比较动画和减少动态效果下的静态图片；检查吉祥物周围的透明区域与边缘，浅色和深色背景都要覆盖。
- 覆盖 WebGL2 和 WebGL1、不同缩放比例与设备像素比；需要在目标浏览器和显卡上验证，不能仅凭素材预览或单个像素判断页面最终合成效果。
- 保持 `e2e/auth-mascot.spec.ts` 的动画、静态回退及透明区域检查；调整纹理管线后运行该专项测试并人工查看真实浏览器效果。
